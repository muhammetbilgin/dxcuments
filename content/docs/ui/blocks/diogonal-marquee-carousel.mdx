## Usage

```tsx

export function Example() {
  return <DiagonalMarqueeCarousel className="h-screen" />
}
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `cards` | `CardItem[]` | sample images | Cards with `id`, `url`, and `title` |
| `angle` | `number` | `-25` | Tilt in degrees |
| `duration` | `number` | `120` | Base row duration in seconds |
| `alternateDirections` | `boolean` | `true` | Reverse every other row |
| `className` | `string` | — | Root class name |
| `cardClassName` | `string` | — | Classes for each card |
| `fadeClassName` | `string` | — | Classes for top/bottom fades |
