A floating bottom dock. Select a tab to open its menu of toggles and actions; click again or outside to close.


## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `tabs` | `NavTabItem[]` | built-in set | Tabs and their menu items |
| `defaultActiveIndex` | `number \| null` | `null` | Initially open tab index |
| `menuWidth` | `number` | `310` | Menu panel width in px |
| `showIcons` | `boolean` | `true` | Show tab icons |
| `onTabChange` | `(index: number \| null) => void` | — | Called when the open tab changes |
| `onItemToggle` | `(tabId, itemId, enabled) => void` | — | Called when a toggle item flips |
| `isFixed` | `boolean` | `true` | Pin to the viewport bottom |
| `className` | `string` | — | Root class name |
