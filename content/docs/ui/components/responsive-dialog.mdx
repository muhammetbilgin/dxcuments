---
title: Responsive Dialog
description: Dialog on desktop, drawer on mobile.
---

Renders a Radix dialog above the desktop breakpoint and a drawer on smaller viewports. Depends on `use-is-desktop` plus shadcn `button`, `dialog`, and `drawer`.

## Usage

```tsx
import { Button } from '@/components/ui/button'
import { ResponsiveDialog } from '@/components/ui/responsive-dialog'

export function Example() {
  return (
    <ResponsiveDialog
      title="Edit profile"
      description="Make changes to your profile here."
      trigger={<Button variant="outline">Open</Button>}
    >
      <p className="text-sm text-muted-foreground">Form fields go here.</p>
    </ResponsiveDialog>
  )
}
```
