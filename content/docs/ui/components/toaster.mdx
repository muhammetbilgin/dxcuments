DX Toaster wraps [Sileo](https://sileo.aaryan.design/docs) — physics-based gooey toasts. Basic helpers in `lib/toast.ts` play [Cuelume](https://www.npmjs.com/package/cuelume) sounds by default. Place `<Toaster />` once in your root layout.

## Setup

```tsx
import { Toaster } from '@/components/ui/toaster'

export default function RootLayout({ children }) {
  return (
    <html>
      <body>
        {children}
        <Toaster position="top-right" />
      </body>
    </html>
  )
}
```

## Usage

```tsx
import { toast } from '@/lib/toast'

toast.success('Saved', { description: 'Your changes are live.' })
toast.error('Failed', { description: 'Something went wrong.' })
toast.warning('Careful')
toast.info('Tip')

await toast.promise(save(), {
  loading: 'Saving…',
  success: (data) => `Saved #${data.id}`,
  error: 'Could not save',
})
```

### Custom Sileo toast

```tsx
import { sileo } from 'sileo'

sileo.success({
  title: 'Brand toast',
  description: 'Custom fill + rounded corners.',
  fill: '#111827',
  roundness: 22,
  styles: {
    title: 'text-white font-semibold',
    description: 'text-zinc-300',
    badge: 'bg-emerald-500 text-white',
  },
})
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `position` | `SileoPosition` | `"top-right"` | Default toast position |
| `options` | `SileoOptions` | — | Shared Sileo defaults |

Theme follows `document.documentElement` light/dark class automatically.
